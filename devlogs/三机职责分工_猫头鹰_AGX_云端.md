# 四端职责分工：猫头鹰 · 本机 · AGX · 云端

> 版本：2026-10-21b  
> 用途：定责、排障、写开发日志时对照。  
> 硬件：Orin NX（猫头鹰）· 本机 Ubuntu+RTX5060（第二任务台）· AGX Orin 32G（强推理）· 云 `39.96.82.193`（TC/Alpha CPU）

---

## 1. 一句话定责

| 角色 | 一句话 |
|------|--------|
| **猫头鹰助手** | **第一交互入口**：人机交互 + 全部秘书事务；Orin NX + 小模型。 |
| **本机（第二任务台）** | **你不向猫头鹰下令时**，在这里发布任务、编排 Agent、开发与验收；5060 跑 7B+LoRA。 |
| **AGX Orin 32G** | **强推理算力池**：20B/14B 只在这里加载，给猫头鹰或本机调用。 |
| **云端** | **TC/Alpha 7×24 CPU 后台**：企微、课程、检索、备份；不训大权重。 |

### 入口优先级（发布任务时）
1. **有猫头鹰在侧** → 优先对猫头鹰说（秘书/催办/转达）。  
2. **不向猫头鹰下令时** → **本机**发布任务（Agent / TC / 调 AGX / 看云端）。  
3. 重推理一律落到 **AGX**；科研长跑落到 **云端/本机 TC**，不塞给猫头鹰硬算。

## 2. 猫头鹰助手（Orin NX）— 人机交互 + 秘书全责

### 2.1 必须承担
- **人机交互**：对话、表情/状态、语音入口（ASR/TTS 接入后）。
- **秘书事务**：日程提醒、待办、纪要摘要、文件归类提示、进度催办、简报。
- **轻量记忆检索**：embedding；不替代 TC 证据库。
- **路由**：深推理 → 本机 Agent 或直接 AGX；不自己扛 20B。
- **外设协调**：麦、唤醒、表情硬件（服务层，不只靠模型）。

### 2.2 明确不做
- 不常驻 14B/20B；不跑 TC `main.py`/DELIVER；不改 locked metrics。  
- 不在 exFAT 上跑 venv；U 盘仅模型仓库。

### 2.3 模型（U 盘已备）
`Owl_Secretary/01_LLM_Models/ollama_store`：`qwen3:4b` / `1.7b` / `coder:3b` / `embedding:0.6b` / `vl:4b`。

## 3. 本机（Ubuntu + RTX 5060）— 第二任务发布平台

> 定义：**当你不向猫头鹰下达指令时，默认在本机发布和管理任务。**

### 3.1 必须承担（任务发布与编排）
- **任务发布台**：创建/下达/改派科研与工程任务（TC `main.py`、Agent 对话、脚本、部署指令）。
- **Agent 宿主**：Open WebUI / companion webapp / 自研 Agent；接用户意图 → 拆任务 → 调工具。
- **对下调度**：
  - 重推理 → **AGX**（`http://AGX_IP:11434`，如 `gpt-oss:20b`）
  - 科研长跑/企微/课程备份 → **云端** 或本机直接跑 TC
  - 秘书类、人侧提醒 → 可回写/同步给 **猫头鹰**（若在线），否则本机自己记待办
- **开发与打包**：改代码、写 `09_DevLogs`、打部署包、U 盘模型整理。
- **验收台**：看云端 probe、AGX `ollama list`、TC STATUS、防泄考试结果。

### 3.2 必须承担（本地算力）
- **常驻轻推理**：Qwen2.5-**7B** GGUF（优先 Q5，备 Q4）+ Alpha **LoRA**（`AlphaCmd/lora/...`）。
- **按需**：本机也可短时打 14B GGUF，但优先把 14B/20B 放到 AGX，避免和桌面抢 8GB。
- **HF 7B 全量**：仅 QLoRA/训练相关；日常对话用 GGUF。

### 3.3 本机任务清单（日常勾选）

| 任务类型 | 本机动作 | 下游 |
|----------|----------|------|
| A. 发布秘书类（无猫头鹰时） | Agent/待办里下达提醒、纪要、催办 | 猫头鹰上线后可同步；否则本机执行 |
| B. 发布强推理题 | Agent 把 prompt 发到 AGX API | AGX 20B/14B |
| C. 发布科研/投稿任务 | `cd workers` → `main.py` / CEO 台 / auto-run | 云端常驻环 + 本机干预 |
| D. 查进度 | 读 STATUS / cloud probe / 问 Alpha | 云端、本机产物 |
| E. 部署与下载管理 | 模型拷贝、Docker/webapp、续传说明 | NX / AGX / U 盘 |
| F. 写开发日志 | `09_DevLogs/DEVLOG_*.md` + ISSUE | U 盘索引 |

### 3.4 明确不做
- 不替代猫头鹰做人设/表情/语音硬件主入口（那是 NX）。  
- 不把 20B 长期钉在 5060 上。  
- 不假装云端「课通过数」= 能力已验收。

### 3.5 本机已有资产（安排）
| 资产 | 用途 |
|------|------|
| `~/models/gguf/qwen25-7b` | 本机 Agent 常驻 |
| `~/models/gguf/qwen25-14b` | 备用；优先拷/留给 AGX |
| 系统 Ollama `qwen3:8b` / `14b` | 本机或迁 AGX |
| `AlphaCmd/lora/*` | 本机 7B 个性/文档适配 |
| `workers` + companion | 任务发布与 TC |
| U 盘 Owl store | **不在本机常驻服务**；给 NX |

### 3.6 验收口径（本机任务台）
- 不靠猫头鹰也能：发布一条任务 → 看到回执（本地完成或已甩到 AGX/云端）。  
- Agent 入口可打开（webapp 或 WebUI）。  
- 日志设备字段能标 `host`。

## 4. AGX Orin 32G — 强推理

### 4.1 必须承担
- 重模型服务（`gpt-oss:20b` 等），局域网 API。  
- 承接猫头鹰或**本机**甩来的深推理/长代码。  
- 一次主常驻一个大模型；OOM 按退让阶梯：20B → 14B → R1-14B 蒸馏 → 回本机 7B。

### 4.2 不做
- 不当第一/第二「发布任务」入口（入口是猫头鹰或本机）。  
- 不跑秘书硬件栈；不跑云端课程刷题环。

---

## 5. 云端 — TC/Alpha CPU 后台

### 5.1 必须承担
- 企微/移动状态、课程环、研究网、图风学习、投稿状态机、备份同步。  

### 5.2 不做
- 不下/不训大权重；不做人机秘书；不跑 20B。  
- 体量指标 ≠ 验收（防泄/held-out 为准）。

## 6. 协作关系

```
        ┌─ 优先 ─→ 猫头鹰(NX) ──秘书──→ 用户
用户 ───┤
        └─ 不令猫头鹰时 ─→ 本机(第二任务台/Agent/TC)
                              ├─ 重推理 ─→ AGX
                              └─ 科研长跑/企微 ─→ 云端
```

| 场景 | 主发布入口 | 执行 |
|------|------------|------|
| 当面秘书、提醒、传达 | 猫头鹰 | NX 小模型；必要时本机/AGX |
| 你坐在电脑前下任务 | **本机** | Agent/TC；重活 AGX；长跑云端 |
| 只要算力、不要闲聊 | 本机或脚本直调 | AGX |
| 投稿/课程/检索常驻 | 本机下达或云端自转 | 云端 |
