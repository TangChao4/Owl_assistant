# 协作模式：本机 · AGX · 云端

AGX 端点：`192.168.90.3:11434` · 模型：`gpt-oss:20b`  
SSH：`ssh agx`（用户 `ubuntu`）

---

## M1 — 本机与 AGX 协同

```
你 → 本机 Agent / workers
        ├─ 轻任务 → 本机 7B（可选）
        └─ 重推理 → AGX gpt-oss:20b
```

- 本机负责：发布、拆分、工具调用、写日志、调云端。  
- AGX 负责：20B 推理 API（可被多客户端调用）。  
- 验收：本机 `curl http://192.168.90.3:11434/api/tags` 通；Agent 对话走 20B。

---

## M2 — AGX 单独干活

```
你 → SSH/板载终端 → AGX（ollama / 脚本）
（本机可关机；云端可不参与）
```

- 适用：批推理、长思考、板载实验、断网笔记本场景。  
- 操作：`ssh agx` → `ollama run gpt-oss:20b`  
- 注意：结果需自己 `scp`/U 盘带回本机或云；无人值守时用 `nohup`/`tmux`。

---

## M3 — 云端参与

```
你 → 本机（可选）→ 云端 TC/Alpha 环
                ↘ 难点 ↔ AGX（经本机或脚本）
```

- 云端：企微、课程、检索、图风、投稿状态、备份。  
- 不在云端跑 20B；强模型仍在 AGX。  
- 本机：`cloud_status_probe` / SSH 云机查环；需要补推理时走 M1。

---

## 怎么选

| 场景 | 模式 |
|------|------|
| 日常开发、Agent 聊天、边写边问 | **M1** |
| 人在板子旁 / 只要猛算 | **M2** |
| 投稿长跑、企微、课程后台 | **M3**（± M1） |
| 秘书闲聊、提醒 | 猫头鹰（可再转发 M1/M2） |

开发日志里请标注当日模式：`mode=M1|M2|M3|M1+M3`。
